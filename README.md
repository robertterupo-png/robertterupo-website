## 📑 Structure
- **Main CV** → [`main.html`](main.html)  
  Contains my executive summary, role fit for PNG Air Payroll Manager, achievements, and career snapshot.

- **Skills** → [`skills.html`](skills.html)  
  Dedicated page for technical skills including payroll systems, automation, finance, and web development.

- **Education** → [`education.html`](education.html)  
  Details my academic background including Diploma in IT and Grade 12 Certificate.

- **References** → [`references.html`](references.html)  
  Lists professional referees with direct contact information.

- **Contact** → [`contacts.html`](contacts.html)  
  Provides postal address, phone numbers, email, website, LinkedIn, and GitHub.

## 🛠️ Features
- Fixed navigation bar for quick section jumps  
- Smooth scrolling and active section highlighting  
- Print‑friendly layout with a **Download PDF** button  
- Consistent styling across all pages  
- Accessible markup with ARIA labels for screen readers  
- SEO‑ready with meta descriptions and Open Graph tags for social sharing
